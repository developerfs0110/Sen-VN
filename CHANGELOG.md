# Changelog

All notable changes to **Sen-VN** are documented in this file.

## [1.2.0] - 2026-11-11

### Added
- **Native `SEN-STD-SDLC-001` (`SSDS v1.0.0`) Engine (`internal/ssds` & 9th Command `sen sdlc`):** Compiled all 7 Parts / 28 Sections of the SEN Software Development Standard into a deterministic Go engine (`classify`, `status`, `gate`, `review`, `approve`, `impact`, `exception`, `sync`, `version`) backed by 3 normalized SQLite tables (`ssds_project`, `ssds_phases`, `ssds_governance` — 8 WAL tables total).
- **Zero-Prompt Automatic Activation & Pre-Execution Write Firewall (`internal/bridge`):** `PreInvocation` auto-detects bilingual Vietnamese/English software requests (even in uninitialized folders), runs Brownfield Repo Audits (§2.3), bootstraps adaptive `WF_MICRO | WF_STANDARD | WF_CRITICAL` lifecycles, and injects the mandatory `[SSDS v1.0.0 — Đã kích hoạt tự động]` Workflow Declaration banner, while `PreToolUse` and `sen begin` physically block premature code writes in `P0..P3`.
- **27 Engineering Roles, Honest Review, 6-Link Traceability, CIA & Time-Bounded Exceptions:** Enforced `author_role != reviewer_role`, automatic `INDEPENDENT_AI_REVIEW -> SELF_REVIEW` downgrade disclosure without an independent `--ref`, SHA-256 baseline locking on approved `P1`/`P2` docs requiring 10-dimension `CIA-*` records (§17), 6-link `docs/traceability-matrix.md` verification (§16), anti-fake-PASS QA checks (§11/§20), `WF_CRITICAL` `force_ask` brakes even under `--express` (§21), and `EXC-*` expiration gates (§27).
- **Multi-Project Isolation & Independent SSDS Standard Versioning:** Added target-path nearest-project resolution (`workspace.ResolveNearestProjectRoot`), CLI `--project <dir>`, subproject crossing prevention (`CheckNoSubprojectCrossing`), per-project SHA-256-signed `ssds_version` pinning preserved across `sen init` / `--express`, read-only `--check`, user-approved `--upgrade`, and instant `--rollback`.
- **Global Antigravity Hook Installer Merge:** Updated `scripts/install-sen.ps1` (`-ConfigureHooks`) and `scripts/install-sen.sh` (`--no-hooks`) to merge `"sen-vn"` lifecycle hooks cleanly into `~/.gemini/config/hooks.json` without overwriting other user hooks.

## [1.1.0] - 2026-11-11

### Added
- **3-Tier Deterministic Task Sizing (`SMALL` / `MEDIUM` / `LARGE`):** Upgraded `ComputeRisk` / `ComputeRiskWithOpts` in `internal/workspace/risk.go` to classify tasks into `SMALL` (`<= 2` standard files), `MEDIUM` (`3–5` files), and `LARGE` (`> 5` files, `BUGFIX`, `--allow-delete`, or critical auth/payment/DB/CI paths) while keeping the frozen 5-table SQLite schema unchanged.
- **Autonomous `--express` (*"Làm luôn đi"*) Mode with Tamper-Proof Config Guard:** Added `express_mode` to SHA-256-signed `.sen/config.json`, automatic intent detection (`"làm luôn đi"`, `"lam luon di"`, `"just do it"`, `"chạy thẳng"`) in `PreInvocation`, and safety gates in `PreToolUse` forcing human confirmation (`force_ask`) on destructive (`--allow-delete`), critical (`.env`, `auth/`, `payment/`, DB migration), or tampered-config edits.
- **Bounded Repair Loop (`<= 3` Rounds / `[QUARANTINE 3/3]`) & Dialectical Audit (`sen-dialectical`):** Added consecutive failure counting on `evidence`, immediate quarantine blocking on the 4th attempt, `Stop` hook loop-prevention (`allow` when quarantined), human unlock via `sen status --approve`, and the progressive `sen-dialectical` skill (**Thesis -> Antithesis -> Synthesis** + **Resource Cost** table).
- **Workflow Skill Capture (`sen-skill-capture`) & Multi-Domain Profiles (`--profile`):** Added `sen-skill-capture` skill and `DomainProfile` auto-detection (`code`, `web`, `video`, `media`, `docs`) so non-code workspaces (`docs`, `video`, `media`) verify and pass `sen done` cleanly without requiring dummy unit-test suites.
- **Video Production Integrity (Immutable Raw Media Lock + `ffprobe` Referee):** Locked `raw/`, `master/`, `footage/`, and `originals/` media files (`>10MB` tracked via zero-copy `size + mtime_ns`), blocked destructive/in-place `ffmpeg` raw overwrites in `PreToolUse`, and added `internal/verify/ffprobe.go` (`MEDIA` strength) rejecting corrupt/0-stream outputs even when `ffprobe` exits `0`.
- **Auto-Install Companion Bundle, Fork Fallback & Optional Packs (`packages.lock.json` + `--update`):** Added `sen init --install-companions`, `sen init --packs list|all|<csv>`, embedded offline skills (`archify`, `voicestudio`, `video-subtitles-effects`, `sen-dialectical`, `sen-skill-capture`), automatic `developerfs0110/...` Git fork fallback pinned by commit, skip-existing protection (`[exists]`), enhanced `.sen/delivery-report.md`, and atomic `.bak`-backed updates via `sen init --update` (`install-sen.ps1 -Update` / `install-sen.sh --update`).

## [1.0.0] - 2026-11-11

### Added
- **Frozen 8-Command Go CLI (`cmd/sen`):** Implemented `init`, `brief`, `intake`, `begin`, `verify`, `undo`, `done`, and `status` using pure-Go `modernc.org/sqlite` (zero CGO, zero external LLM dependencies).
- **5-Table SQLite WAL Ledger (`internal/storage`):** Created `rules` (`<= 20` hard cap with `--replace`/`--delete`), `requirements` (`R1..Rn`, `R_sec`, `R_law`), immutable `tasks`, `snapshots`, and canonical-JSON SHA-256 hash-chained `evidence` (`GENESIS` -> `entry_hash`).
- **Git-Independent Workspace Integrity & Undo (`internal/workspace`):** Added `__BASELINE__` manifest tracking (advancing cleanly on `VERIFIED` tasks), `>10MB` media copy-skip (`size + mtime_ns` tracking), NTFS junction/symlink escape rejection, pre-existing test SHA-256 locking (`is_locked_test = 1`), deterministic `ComputeRisk`, and byte-for-byte `sen undo`.
- **Direct Subprocess Verification & `done` Gate (`internal/verify`):** Enforced safe `PATH` binary resolution (blocking shell interpreters, `%TEMP%`/workspace spoofing, and non-Node `.cmd`/`.bat` wrappers), child environment scrubbing, secret redaction (`[REDACTED]`), empty-test rejection across `go test`, `pytest`, and `jest`/`vitest`, `TEST`-strength enforcement on `BUGFIX` tasks, and 100% SQL requirement coverage in `sen done`.
- **Native Antigravity Plugin & Zero-Build Packaging:** Added `plugin.json`, root `hooks.json` (with plugin `cwd` -> user workspace isolation), `rules/AGENTS.md`, `skills/sen-setup/SKILL.md`, cross-platform zero-build smart wrappers (`bin/sen.cmd`, `bin/sen`, `scripts/bootstrap-sen.ps1`), HTTPS SHA-256 installers (`scripts/install-sen.ps1`, `scripts/install-sen.sh`), and GitHub Actions CI + 6-target Multi-OS Release workflows (`.github/workflows/ci.yml`, `.github/workflows/release.yml`).
