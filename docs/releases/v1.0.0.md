## 1. Điểm Nhấn Chính

- **CLI Go thuần túy (8 Lệnh Cốt Lõi):** `init`, `brief`, `intake`, `begin`, `verify`, `undo`, `done`, `status` (zero CGO, zero Docker, zero API keys).
- **Sổ cái SQLite WAL 5 bảng:** `rules`, `requirements`, `tasks`, `snapshots`, `evidence` (chuỗi băm SHA-256 từ `GENESIS`).
- **Toàn vẹn không gian làm việc & Hoàn tác không phụ thuộc Git:** Quản lý snapshot `__BASELINE__` độc lập, chống trốn thoát liên kết junction/symlink NTFS, khóa băm file test sẵn có, hoàn tác chính xác từng byte `sen undo`.
- **Kiểm chứng tiến trình trực tiếp & Cổng `sen done`:** Thực thi kiểm thử độc lập (`go test`, `pytest`, `vitest`), từ chối test rỗng, che giấu dữ liệu nhạy cảm `[REDACTED]`, và yêu cầu độ phủ 100% yêu cầu trước khi nghiệm thu.
- **Bao gói Zero-Build Native Antigravity Plugin:** Cung cấp `bin/sen.cmd`, `bin/sen`, `scripts/bootstrap-sen.ps1` và bộ cài đặt HTTPS SHA-256 tự động.
