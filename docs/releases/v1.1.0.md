# Sen-VN v1.1.0 Release Notes

**Bản phát hành nâng cấp: Phân cấp Tác vụ Xác định, Chế độ Tự hành --express & Bảo toàn Đa Phương tiện**

- **Ngày phát hành:** 2026-11-11
- **Phiên bản:** `v1.1.0`

---

## 1. Điểm Nhấn Chính

- **Phân loại rủi ro tác vụ xác định (3 Tiers):** `SMALL` (`<= 2` files tiêu chuẩn), `MEDIUM` (`3–5` files), `LARGE` (`> 5` files, sửa bug, `--allow-delete` hoặc chạm đường dẫn nhạy cảm).
- **Chế độ tự hành an toàn (`--express`):** Tự động phát hiện ý định ủy quyền (*"làm luôn đi"*, *"just do it"*) với phanh khẩn cấp (`force_ask`) khi có nguy cơ xóa file hoặc sửa file nhạy cảm.
- **Giới hạn vòng lặp sửa lỗi (`<= 3` Rounds):** Đếm số lần kiểm chứng thất bại liên tiếp trên bảng `evidence`, tự động cách ly `[QUARANTINE 3/3]` ở lần thứ 4 để chống đốt token vô ích.
- **Kỹ năng Phản biện Biện chứng (`sen-dialectical`):** Thẩm định chuyên gia qua 3 bước: Chính đề (Thesis) -> Phản đề (Antithesis) -> Hợp đề (Synthesis) kèm bảng so sánh tiêu tốn tài nguyên.
- **Đóng gói kỹ năng lặp lại (`sen-skill-capture`):** Tự động nhận diện quy trình lặp lại 2–3 lần để đóng gói thành skill tái sử dụng.
- **Bảo toàn tính toàn vẹn video/media:** Khóa bất biến tệp media thô (`raw/`, `master/`, `footage/`) và sử dụng trọng tài `ffprobe` thẩm định luồng stream thực tế.
